# AI Agent Learning Notes

An AI agent is a system that uses an AI model to work toward a goal and may use tools to perform tasks.

## Tool Calling
The model can request that a particular tool be executed. The application is responsible for executing the actual Python function and returning its result.

## Validation
Tool arguments must be checked before the function runs. The application should not blindly trust arguments generated by the model.

## Control
The application decides which tools are available and which tool calls it will accept.

## Recovery
When a tool fails, the application should handle the error clearly instead of crashing unexpectedly.

## Important Limitation
A tool can retrieve information from a document, but the retrieved text does not automatically guarantee that every AI-generated answer will be correct.
